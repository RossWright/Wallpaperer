Wallpaperer

Place a picture on each monitor, then apply them as one spanned wallpaper on GNOME.

Version 0.1.0

Download .deb Download AppImage Source

Install

The buttons download the files attached to the latest GitHub Release. They are not stored in the git repository.

sudo apt install ./wallpaperer_amd64.deb

Or run the AppImage. To build either one yourself:

./packaging/build.sh
