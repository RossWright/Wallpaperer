# Filter wallpapers by size (default to monitor sizes)

Add a dropdown to the top of the found picture tiles. It should have "Any" and then an entry for all the popular screen resolutions. It should include entries for spanning resolutions relevant to the current monitor setup (so I'd see entries for 2-monitor spans veritically and horizontally and 3 monitor-spans horizontally). Each entry corresponds to a range of resolutions and changing the dropdown filters the list to pictures in that range. The setting on the filter should be persisted between sessions.
